Ghorify

This is a preview

This GitHub Pages site is a static preview of Ghorify, so you can browse the home page, listings and property details. Logging in, Smart match search, favourites, comparison, visit booking, rental applications and the admin panel need the Django server.

Run the full app
git clone https://github.com/shimanto-0922/Django-Project.git
cd Django-Project
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver

Then open http://127.0.0.1:8000. Demo password for every account: ghorify123 (admin, rahim, tanvir).
